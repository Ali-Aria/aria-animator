# 视觉设计

## 从内容选择主体

按 [口播与画面信息分工](information-design.md) 确定每段讲什么、展示什么，再说明什么改变、原因是什么、结果如何可见。把内容拆成输入、执行主体、反馈和结果，包括口播未逐字念出的信息。
例如，按钮要有点击及反馈；数值变化要使用正确标尺；关系要通过连线、位置或传递呈现。

先设计主体形状、层次和响应，再安排动作时间。按内容选择表现方式，简要记录原因。
一段可以跨越多句话；同一句也可以包含多个有依据的变化。

| 内容 | 可用的表现方式 |
| --- | --- |
| 软件操作 | 真实界面状态及反馈 |
| 系统流程 | 相连主体和信号传递 |
| 对比 | 共同标尺、对应形状或直接替换 |
| 数量随时间改变 | 轴线和单位准确的图表或波形 |
| 符号变化 | 有中间步骤的公式 |
| 空间关系 | 2D 区域和分层；3D 适用条件见主文件 |

区分实测事实、示意归一化和推测。保留技术主题的拓扑、守恒关系、中间转换和安全条件。
跨段主体的身份、位置、状态和移除条件按 [场景组织](scene-organization.md) 记录。

## 先确定构图

用一句话确定场景及其运作方式，例如“电路工作台上的能量沿元件传递”。
优先安排最有解释作用的内容，让主体足够大，并为下一步动作留出空间。
把复杂系统拆成可编辑、可响应的部件。用层次表达关系，同一概念保持可识别的形状、比例、位置或颜色。

先设计可读的结果静帧，再设计准备和揭示顺序。主体在承担解释任务时出现。
避免先摆满全部部件，再等到后面的关键词才开始动作。出现时机和停顿按 [动作编排](motion-production-patterns.md) 执行。
需要表现重量或气氛时，可用有依据的次级动作；证据图片遵循下文的固定展示规则。

## 统一轮廓线宽

青瓷蓝、椰林绿、编辑部红和石墨青共用以下默认线宽，适用于新绘制的图解。数值以 1080p 落稳画面中的可见粗细为准。

| 用途 | 1080p 默认线宽 |
| --- | --- |
| 主体轮廓，如节点、图标外框和文件边界 | 8 px |
| 连线，如流程箭头和关系线 | 6 px |
| 辅助细节，如图标内部线条和次要分隔 | 4 px |

检查局部缩放、镜头缩放和输出缩小后的实际粗细。960×540 预览中，这三档分别对应 4 px、3 px 和 2 px。局部缩放使线条过细时，补偿描边宽度或将描边放在不缩放的图层；不要只检查源码中的 `strokeWidth` 数值。
箭头头部与连线保持清楚的粗细关系，连线避开标签。按实际播放尺寸复查轮廓、内部细节和文字间距。复用镜头时按用途调整原有线宽，不再叠加旧版 `strokeScale: 1.8`。原始界面和证据图片保留原有线条。

## 控制文字

字幕承载确认的口播文案，正式时间取自成品音频。独立大标题仅用于重要的开头、章节或结尾，全片最多保留 1～2 次。

图表标签、对照数值、对象名称和操作反馈可以承载口播之外的信息。这些文字归属画面主体，与口播字幕分开管理，不写进逐字字幕或配音输入。用户关闭字幕时，仍按解释需要保留这些文字；用户要求画面无文字时，改用可辨识图形或按授权调整口播。

新增文字须说明必要的事实、数值、状态、方向、交互或安全条件。
按本段的信息目标判断是否保留，不能只因口播没念到就删除。删除后不影响解释目标和事实理解的文字再删；确有必要时，使用靠近主体的最短标签，并安排退出时间。
口播、字幕和主体标签允许共同强调关键结论，其他内容按分工呈现。密集读图时减少其他新信息，稳定构图；阅读窗口与错峰规则见信息分工文档。
日期、章节标签、角落元数据、说明卡片、进度条和装饰文案默认不添加。

禁止沿画面边缘新加注释、标签或解释条，即使复用镜头带有这些位置。
字幕和原界面、代码、图表或文档中的文字可保留。避免用新标注重复证据原文。
必要的来源说明放在对应证据旁，避免形成反复出现的页脚或角标。

## 展示证据图片

用户提供的图片须完整、足够大，使用 contain-fit（完整适配）。默认安排短暂入场、固定阅读和短暂出场。用户要求静态展示时，关闭进出场。
完整图片及对应强调层共用一个屏幕图层，从右进入并向左退出。使用按帧计算的非线性缓动，入场默认 ease-out-back，略微越位后落稳；出场默认 ease-in-out。`process` 默认入场 0.4 秒、出场 0.3 秒，可按内容调整。
阅读起止时间保持原计划含义。入场在阅读开始前执行，出场在阅读结束后执行。过渡超出片长或与必要内容冲突时，调整过渡窗口，并记录原因。落稳到出场开始之间的位置和尺寸保持固定，阅读期间四角均须可见。
图片及强调层放在移动世界之外。离场与下一主体适度交叠，避免空白或画面突然消失；父级变换不能在阅读期间移动或裁切图片。

圆圈、线、点、遮罩和调暗区域可以引导注意力，须对应整张图片的位置。
强调层不能替换、裁切或永久遮住证据。不要用 cover-fit、平移或缓慢缩放模拟镜头。
细节看不清时，调整证据展示方式或使用获准的高分辨率来源。
复用 `assets/shot-library/src/motion/EvidenceTransition.tsx` 和 `evidence.ts`，同时复制 `runtime.ts`。图片、强调层和必要的白底放在同一容器内，字幕放在容器外。按 [process 制作与接入](process-production.md) 保留进出场时的组件生命周期。
默认单图及对比例外见 [界面镜头库](ui-motion-shot-library.md)。
