# 音效设计与接入

AI 按可见事件自主选择音效和音量。用户要求无音效时跳过本流程。

## 选择声音

音效对应已经设计好的动作和反馈，保持配音清楚可听。

| 可见事件 | 可用音效 | 声音对应的时刻 |
| --- | --- | --- |
| 点击或选中 | 短促点击声 | 控件触发或选中反馈 |
| 主体移动或传递 | 轻微扫动声 | 可见移动区间 |
| 碰撞或部件落位 | 克制的撞击声 | 接触或落位帧 |
| 成功、错误或结果确认 | 简短提示音 | 结果实际出现的帧 |

同类事件复用声音，密集输入可合并。固定截图阅读和无变化的等待保持纯配音。
结果提示须与实际结果同步。音效不能替代界面反馈，也不能据此声称真实产品会发出同样的声音。

## 准备素材

优先从 [内置音效目录](../assets/sound-effects/catalog.json) 选择已有声音。
这 6 种声音由代码独立合成，可按项目需求试听选用。目录记录用途、时长、起音偏移和文件校验值。
先复用项目已有素材，再用 [prepare_sfx.py](../scripts/prepare_sfx.py) 复制所需声音。脚本仅使用 Python 标准库，校验 WAV 元数据和 SHA256。

在 Skill 根目录执行，替换命令中的项目路径：

```powershell
python scripts/prepare_sfx.py --output "<项目目录>/public/audio/sfx" --ids soft-click air-whoosh glass-confirm
```

省略 `--ids` 会复制全部 6 种声音。相同文件再次执行时直接复用；同名文件内容不同时报错，保留原文件。
其他素材须由用户提供、具备许可或独立合成，记录来源和许可。
保存到项目的 `public/audio/sfx/` 后，听检起音、主峰和尾音，测量时长。
网络合成只使用当前环境中已授权的服务，不借用配音服务配置。

## 生成和缓存

优先调整已有素材的时间、增益、音高或裁切。特殊声音在制作阶段用代码生成一次，试听后缓存。
项目保留生成器、算法版本、随机种子和合成参数，并与输入素材校验值组成缓存标识。
参数不变时复用文件；新增变体使用新标识和文件名。只改触发帧或播放音量时，无需重新生成。
React 组件和逐帧渲染只读取本地文件。跨项目复用时复制声音和来源记录，保留安装目录的素材库。

## 记录事件

音效沿用视频的帧率和全局时间线，引用 `choreography-plan.json` 中的动作事件。
按实际动作或反馈帧同步声音，不能统一复制字幕起点。

在 `src/data/audio-events.json` 中记录事件。以下文件名和数值须替换为实际结果。

```json
{
  "enabled": true,
  "fps": 30,
  "events": [
    {
      "id": "confirm-click",
      "visualEventId": "confirm-button-click",
      "src": "audio/sfx/01-soft-click.wav",
      "startFrame": 720,
      "anchorFrame": 722,
      "anchorOffsetFrames": 2,
      "durationInFrames": 14,
      "gainDb": -6,
      "source": "内置素材库：soft-click，校验值见 catalog.json",
      "license": "CC0-1.0"
    }
  ]
}
```

`anchorFrame` 是动作重点的全局帧，`anchorOffsetFrames` 是声音锚点在素材内的偏移。
用 `startFrame = anchorFrame - anchorOffsetFrames` 计算非负整数起点。
内置素材有 0.08 秒前导静音，按当前帧率换算偏移。必要时裁切项目副本，保留自然尾音。
扫动声按可见移动区间安排，主峰对应动作重点。

`durationInFrames` 按素材实测时长和所需尾音确定，且不超过视频结束帧。
`gainDb` 表示相对素材原音量的分贝增益，示例数值只作为试听起点。
改变帧率时，按真实秒数重新计算事件帧，核对声音锚点。

## 接入 Remotion

使用项目已安装的 Remotion 音频组件，在全局时间线根部挂载音效层。
每个事件用 `Sequence` 设置起点和时长，音频路径用 `staticFile(event.src)`，播放音量为 `10 ** (event.gainDb / 20)`。
放入局部时间线时，只转换一次起点。需要淡出或音量包络时，按音频局部帧计算。

接入前校验文件存在、事件标识唯一、帧为整数、时长为正数和增益为有限数值。
预览、跳帧和导出使用同一份事件数据，禁用墙钟定时器和浏览器即时播放调用。

## 混音和交付

修改音效复用成品配音和实测时间。声音重叠时，降低增益或减少事件，保持配音清楚可听。
预览包含启用的音效，正式版沿用确认的事件和素材。按 [制作检查](production-and-qc.md) 检查最终混音并保存证据。

交付独立音效轨，与视频使用同一时间起点和片长，空白区间保留静音，片尾自然结束。
项目保留素材、事件清单和来源记录；最终配音源文件保持纯配音。
