# 界面镜头库

本库收录从界面和 After Effects 研究中提取的通用动作。将机制实现为参数化 Remotion 组件，项目须可独立运行，不依赖私人路径或原工程。
根据讲解内容选择、改编、组合或新写动作。示例的构图、主体形状和动作密度不构成制作要求，素材中的音乐和无关音频不用于成片。

## 应用规则

`defaultProps` 和预览颜色仅用于测试。制作时将自绘颜色改为所选预设的语义色，真实界面和参考证据的颜色按 [配色规则](color-presets.md) 保留。

默认用主体、空间关系、真实界面和状态变化解释内容。`labels`、`callout`、`title`、`subtitle` 和卡片文字都是可选项。
按 [视觉设计](code-motion-design.md) 处理字幕、大标题和必要标签，删除装饰标签、边缘注释和重复解释。地图、教程或事实对比确需更多标签时，按用户任务安排。
主要依赖重复注释、缺少动作或必要关系的候选应弃用。

默认一次展示一张完整、可读的证据图片，使用 `object-fit: contain`。只有明确的来源对比才并列多图，并记录理由。
截图默认从右进入、落稳阅读、向左退出。图片和强调层共用屏幕容器，置于移动世界之外。阅读期保持完整、固定，用户要求静态展示时关闭进出场。
弃用裁切、慢推或漂移图片的模板。短暂进出场按 [视觉设计](code-motion-design.md) 执行，复用 `src/motion/EvidenceTransition.tsx`；不要沿用只在阅读窗口挂载图片的模板。

## 动作目录

### 路径聚焦

用途：沿深色界面或 AI 流程引导注意力。
主体与参数：路径、光晕、节点、网格；配置路径点、进度、光晕半径、焦点色、标签和镜头尺度。
动作：描出路径 → 激活目的地 → 光晕落稳 → 将目的地接入下一段。
默认省去路径标签，目的地不明确时保留一个短标签。没有语义目的地的霓虹装饰应弃用。

### 响应式界面

用途：展示同一产品状态在横屏和竖屏中的布局。
主体与参数：导航、工作区、检查器、浮动操作和安全区；配置画幅、断点、面板宽度、内容密度和当前工具。
动作：重排独立区域，保留状态和操作关系。缩小桌面截图不能代替移动布局。

### 命令到结果

用途：展示提示词或命令触发的产品操作。
主体与参数：输入区、任务节点、连线、状态和结果面板；配置命令、节点数、标签、状态和拓扑。
动作：输入 → 提交 → 分派 → 执行 → 汇合 → 显示结果。
保留命令和结果证据，省去逐节点标签和旁白复述。结果前须有可见的系统响应。

### 音频波形变换

用途：讲解录音、滤波、合成、转写或信号转换。
主体与参数：波形、播放位置、频段、状态和输出；配置样本、幅度、频率、平滑、颜色和时长。
动作：描出输入 → 变换信号 → 比较输出 → 保留实测结果。
波形须对应所讲的转换，随机波形不能充当证据。

### 数据处理流程

用途：讲解输入、处理、分支、聚合和输出。
主体与参数：数据包、节点、队列、过滤器、计数器和输出卡片；配置拓扑、吞吐量、错误状态、分支和标签。
动作：输入 → 路由 → 节点响应 → 聚合 → 确认。
用形状、运动和状态色区分环节，只标必要输出、错误或安全条件。粒子移动时须有节点响应。

### 设计工具变换

用途：演示编辑、合成、布局或设计系统调整。
主体与参数：画布、图层、选区、手柄、检查器和结果对比；配置图层树、选择、边界、属性和前后状态。
动作：选择 → 操作 → 更新检查器 → 显示结果。
保留证明编辑的界面原生文字，省去额外解释气泡。游标运动须伴随可见的编辑结果。

## 选择记录

记录候选的复用、改编或弃用理由，保留主体身份和操作反馈。通用模板须先在两个不同项目中验证，单次制作成功只证明本次可用。

## 本地预览与上游展示

镜头清单保留 59 项。8 个代表组件支持新动作配置；其他组件保留旧接口。`production_status` 描述组件用途，不代表已完成视觉验收。

`upstream-reference-map.json` 将本地镜头映射到上游分类合集。上游源码和参数与本地不一致时，合集只作为参考。上游新增镜头不自动同步，不整体覆盖本地技能。

在镜头库目录运行 `python scripts/render_previews.py --fixtures`，生成全部预览和验证素材。可用 `--only` 按 ID 或 Composition 选择镜头；`--only-missing` 仍会重生成指纹变化的文件。浏览器通过 `--browser` 或 `REMOTION_BROWSER_EXECUTABLE` 指定，也可发现已安装的 Chromium。缺少运行时或浏览器时报告错误，不自动安装。

预览缓存包含依赖源码、实际参数、运行时版本、浏览器、输出配置和成品校验值。转移目录后重新检查缓存。修改源文件不会沿用失效预览。
